# Sprout

A lightweight project creator for Linux with a compact popup interface, language-specific templates, and live Noctalia colors. Works with Niri and Hyprland.

## Features

- Compact, frameless interface with rounded corners.
- Wallpaper-synced colors through Noctalia.
- 26 starter templates across eight languages.
- Projects organized into language folders.
- Optional Git initialization and README generation.
- File preview before creation.
- Open projects in VS Code, Kitty, or your file manager.
- Keyboard navigation and shortcuts.
- Protection against overwriting existing projects.

## Supported languages

| Language | Project types |
|---|---|
| Python | CLI, Library, GUI, API, Empty |
| JavaScript | CLI, Library, Web, Empty |
| TypeScript | CLI, Library, Web, Empty |
| C | CLI, Library, Empty |
| C++ | CLI, Library, Empty |
| Rust | CLI, Library, Empty |
| Go | CLI, Library, Empty |
| Other | Empty |

The templates provide starter files. Install compilers and project dependencies separately.

## Requirements

- Linux
- Python 3.11 or newer
- PySide6
- Git, for repository initialization
- Noctalia v4 or v5, for color synchronization

VS Code and Kitty are optional.

## Installation

On Arch Linux, install the dependencies:

```bash
sudo pacman -Syu --needed pyside6 git qt6-wayland
```

This command also updates your system.

Download `project-creator.py` into `~/Scripts`, then run:

```bash
python ~/Scripts/project-creator.py
```

## Usage

Enter a project name, select a language and project type, then choose the Git and README options.

Click **Show files** to inspect the generated file list. Click **Create project** to create the project.

Projects use this folder structure:

```text
~/Projects/
└── Python/
    └── portfolio/
        ├── .git/
        ├── .gitignore
        ├── README.md
        ├── src/
        │   └── main.py
        └── tests/
            └── .gitkeep
```

The files depend on the selected template and options.

To use another project folder:

```bash
python ~/Scripts/project-creator.py --root ~/Development
```

### Keyboard controls

| Shortcut | Action |
|---|---|
| Tab / Shift+Tab | Move between controls |
| Enter in the project name field | Create the project |
| Enter in a selection box | Open the list |
| Arrow keys | Navigate a list |
| Ctrl+Enter | Create the project |
| Esc | Close an open list or the popup |

## Noctalia colors

The popup can follow the palette generated by Noctalia, including wallpaper-based colors.

Run the setup command for your version.

**Noctalia v5:**

```bash
python ~/Scripts/project-creator.py --setup-noctalia v5
```

**Noctalia v4:**

```bash
python ~/Scripts/project-creator.py --setup-noctalia v4
```

For v4, enable **Settings → Color Scheme → Templates → Advanced → User templates**.

Select wallpaper-based colors in Noctalia. Then change your wallpaper or apply the theme again.

The popup loads palette changes automatically. Before the first palette is generated, it uses its default warm colors.

The setup button is hidden from the interface. Configuration remains available through the commands above.

### Custom configuration paths

```bash
python ~/Scripts/project-creator.py \
  --setup-noctalia v5 \
  --noctalia-dir /path/to/noctalia \
  --theme /path/to/colors.json
```

If you use a custom palette path, pass it when you open the popup:

```bash
python ~/Scripts/project-creator.py --theme /path/to/colors.json
```

## Niri

Add this rule outside the `binds` block in `~/.config/niri/config.kdl`:

```kdl
window-rule {
    match app-id="^project-creator$"
    open-floating true
    open-focused true
    border { off; }
    focus-ring { off; }
}
```

Niri centers new floating windows by default.

To launch the popup with **Super+Shift+P**, add this inside your existing `binds` block:

```kdl
Mod+Shift+P {
    spawn "sh" "-c" "python ~/Scripts/project-creator.py";
}
```

## Hyprland

The window class is `project-creator`.

Add floating and centering rules for that class. The required syntax depends on your Hyprland version. See [SETUP.txt](SETUP.txt) for configuration examples.

## Git integration

The **Git repository** option runs:

```bash
git init --initial-branch=main
```

This creates a **local repository**. It does not create commits, upload files, or create a repository on GitHub.

To create your first commit, run these commands inside the generated project:

```bash
git add .
git commit -m "Initial commit"
```

To publish the project, create a repository on GitHub, add its URL as a remote, and push your commits.

## Notes

- Existing projects are never overwritten.
- Project generation runs without blocking the interface.
- The app does not download dependencies or run generated code.
- Noctalia template setup backs up existing configuration files before changing them.
- Invalid palette updates do not replace the last valid colors.
- The popup is a standalone PySide6 application, not a Noctalia panel.
